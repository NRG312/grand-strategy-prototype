# Strategy Game

A personal project focused on developing a strategy game using Unity and C#.

## About the Project

The goal of this project is to create a strategy game focused on map-based gameplay, territorial control, and strategic decision-making.

The game is currently in the early development stage. Core mechanics, gameplay systems, and the overall direction are still being explored.

## Planned Features

- Map and territory management
- Province selection and interaction
- Army management and movement
- Strategic gameplay systems
- A custom low-poly visual style

## Technologies

- Unity
- C#
- Blender

## Development Status

**Stage:** Pre-prototype

Currently focused on exploring the game's visual direction, designing the map, and planning the core gameplay systems.

## Project Goals

- Build a playable prototype
- Develop modular and maintainable gameplay systems
- Explore different approaches to strategy game design

# Gra strategiczna

Autorski projekt polegający na stworzeniu gry strategicznej przy użyciu silnika Unity oraz języka C#.

## O projekcie

Celem projektu jest stworzenie gry strategicznej, której fundamentem jest rozgrywka na mapie, kontrola terytoriów oraz podejmowanie decyzji strategicznych.

Projekt znajduje się obecnie na wczesnym etapie rozwoju. Trwają prace nad podstawowymi mechanikami, systemami rozgrywki oraz ustalaniem ogólnego kierunku rozwoju gry.

## Planowane funkcje

- Zarządzanie mapą i terytoriami
- Wybór prowincji i interakcja z nimi
- Zarządzanie armią i jej przemieszczanie
- Systemy rozgrywki strategicznej
- Autorski styl wizualny typu „low-poly”

## Technologie

- Unity
- C#
- Blender

## Stan prac

**Etap:** Pre-Prototype

Obecnie skupiam się na opracowywaniu kierunku wizualnego, projektowaniu mapy oraz planowaniu kluczowych systemów rozgrywki.

## Cele projektu

- Stworzenie grywalnego prototypu
- Opracowanie modułowych i łatwych w utrzymaniu systemów rozgrywki
- Eksploracja różnych podejść do projektowania gier strategicznych
